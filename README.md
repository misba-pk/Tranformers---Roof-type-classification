# Berlin Building Type Classification

This project tries to answer a simple question: can you tell whether a building is residential or not just by looking at its footprint and what's around it? I used OpenStreetMap data for about 330,000 buildings in Berlin and labeled them with the city's official cadastral (ALKIS) records. I started by reproducing a published study (Zhou et al., *Scientific Reports*, 2022), and a decision tree on hand-crafted features reached about 92% accuracy across all 12 districts. From there I built two transformer models in PyTorch. One is a graph transformer that looks at each building together with its neighbours, and it reached about 91% accuracy. The other learns straight from the raw polygon outline with no hand-made features, and it reached about 85%. The data prep lives in `src/`, the experiments are in `notebooks/`, and my notes on what worked and what didn't are in `docs/`.
